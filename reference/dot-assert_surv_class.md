# Assert object inherits from a specific surv\_\* class

Assert object inherits from a specific surv\_\* class

## Usage

``` r
.assert_surv_class(x, cls, arg_name = deparse(substitute(x)))
```

## Arguments

- x:

  Object to check.

- cls:

  Expected class name.

- arg_name:

  Name for error messages.

## Value

Invisible TRUE.
